# HymnFlow downloads

**HymnFlow** projects hymn lyrics during church services and lights up the line being sung,
for congregations singing with an organ or piano. Hungarian, Romanian and bilingual hymnals,
PowerPoint import, an autopilot that learns the tempo, MIDI, vMix.

**Download page:** https://hymnflow.szeretet.ro/download/ (which file for which computer, how to install)

The installers of each version are under [Releases](../../releases/latest):
Windows (Intel/AMD and ARM: setup, MSI, portable), macOS, Linux (.deb, AppImage) and Raspberry Pi.

HymnFlow is free to try for 30 days with your church's own PowerPoint files; after that, and for
the szeretet.ro songbooks, a serial per church is needed: https://hymnflow.szeretet.ro

This repository only holds the installers. HymnFlow is not open source.
